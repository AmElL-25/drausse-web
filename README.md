# DRAUSSE — Polos Premium de Algodón Pima Peruano

Landing de e-commerce de una sola página para la marca DRAUSSE. Construida con HTML + Tailwind CSS (CDN) + JavaScript vanilla, sin build ni dependencias.

Incluye: hero, lookbook de categorías, catálogo de productos con filtros, carrito de compras, wishlist, buscador instantáneo, checkout simulado y newsletter.

## Ver el sitio en vivo

https://AmElL-25.github.io/drausse-web/

## Correr localmente

No requiere instalación. Abre `index.html` directamente en el navegador, o sirve la carpeta con cualquier servidor estático, por ejemplo:

```
npx serve .
```

## Estructura

- `index.html` — toda la página (markup, estilos y lógica JS inline)
- `assets/` — imágenes de productos y banner
